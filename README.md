Catálogo de Películas - Actividad 3.4

Este proyecto corresponde a la actividad 3.4 del curso Diseño de Aplicaciones Móviles. El objetivo es construir la interfaz de un catálogo de películas utilizando los widgets básicos de Flutter: Text, Row, Column, Container y Stack.

// Descripción//

La aplicación muestra una interfaz inicial de un catálogo de películas con:

Text: títulos y descripciones.

Row: organización de elementos en filas.

Column: organización vertical de secciones.

Container: tarjetas de películas con estilo.

Stack: superposición de texto sobre imágenes.

// Cómo ejecutar//

Clonar el repositorio:

git clone https://github.com/GERMANGUILLEN/widgets_movies.git

Entrar a la carpeta del proyecto:

cd widgets_movies

Ejecutar la aplicación:

flutter run

// Estructura del proyecto//

lib/main.dart: archivo principal con la interfaz del catálogo.

pubspec.yaml: configuración de dependencias.

README.md: documentación del proyecto.
